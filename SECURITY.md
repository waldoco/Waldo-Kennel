# Security Policy

## Supported versions

Waldo Kennel is an active beta and has no published release yet.

| Source line | Security support |
| ----------- | ---------------- |
| Latest `main` | Supported |
| Current `beta` | Supported for pre-release reports |
| Older commits, forks and local modifications | Not supported |

## Report a vulnerability privately

Use GitHub's [private vulnerability reporting](https://github.com/waldoco/Waldo-Kennel/security/advisories/new).
If GitHub reporting is unavailable, email `woof@heywaldo.in` with the subject
`Waldo Kennel security report`.

Do not disclose a suspected vulnerability in a public issue, discussion, pull
request, transcript or log. Do not include live credentials or private user
data. A useful report contains:

- the affected commit or version and environment;
- the smallest reproducible steps or proof of concept;
- the security impact and required preconditions;
- suggested mitigations, if known.

We aim to acknowledge a report within five business days, then coordinate
validation, remediation and disclosure through the private advisory. Timelines
depend on severity and reproducibility; maintainers will not claim a fix until
it has been verified at an exact revision.

## Research expectations

Use test accounts and data you are authorized to access. Avoid privacy invasion,
service disruption, persistence, destructive actions and lateral movement.
Stop when a proof demonstrates the issue. Social engineering, denial of service,
and testing third-party providers without their permission are out of scope.
