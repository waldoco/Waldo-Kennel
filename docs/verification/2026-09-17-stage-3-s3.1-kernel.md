# Stage 3 S3.1 identity and capability kernel

Baseline: `instinct/stage3-s3.1` at `7589b645bf884bb5ee5439211006806a52a46b27`.

This package implements only the frozen S3.1 semantic spine:

- a durable `HarnessConnection` binding for installation, adapter digest, harness, provider/protocol provenance, mission, app run, capability classes, generation, expiry and revocation;
- a caller-only random bearer with only its SHA-256 verifier persisted;
- issue, authenticate, rotate and revoke operations with fail-closed tuple checks;
- one derived `connected|degraded|action_needed` projection with the frozen reason and repair vocabulary;
- exact issue replay that converges without re-returning or replacing the original bearer;
- SQLite migration/query/store support and migration-ledger registration.

The adapter remains transport only. This package creates no owner authority and does not touch routes, renderer/plugin transport, installer UX, Session schema, Outcome admission, or Stage 4/5 behavior.

## Evidence

- Focused domain, kernel, SQLite store and migration suites pass.
- Focused race suite passes for domain, kernel and SQLite store.
- Tests cover restart authentication, no bearer persistence/API shape, wrong mission/app run/digest/harness/provider/protocol/generation/class, expiry, rotation, revocation, concurrent issuance and concurrent rotation.
- Migration upgrade and rollback are exercised through Goose.
- `git diff --check` passes.

Full backend and repository gates remain required before promotion from the scratch branch.
