# Support

Waldo Kennel is an active beta maintained in public.

- Ask setup, architecture and usage questions in [GitHub Discussions](https://github.com/waldoco/Waldo-Kennel/discussions).
- Report reproducible defects with the [bug form](https://github.com/waldoco/Waldo-Kennel/issues/new?template=bug_report.yml).
- Propose bounded product changes with the [feature form](https://github.com/waldoco/Waldo-Kennel/issues/new?template=feature_request.yml).
- Report vulnerabilities privately using [SECURITY.md](SECURITY.md).

Before posting, check [README.md](README.md), [docs/STATUS.md](docs/STATUS.md),
existing issues and discussions. Include the exact revision and environment,
and remove credentials, private source, transcripts and personal data.

Issues are not a guaranteed response channel or a substitute for a commercial
support agreement. Clear reproductions and focused questions are easier for the
community to help with.
